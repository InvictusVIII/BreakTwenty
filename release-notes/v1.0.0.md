# BreakTwenty 1.0.0

The first public release of BreakTwenty brings your financial life together in one private desktop app for Linux, Windows, and macOS.

## Highlights

- See assets, liabilities, account balances, allocation, and net-worth history in one dashboard.
- Connect supported Canadian banks, brokerages, exchanges, and financial services.
- Search, filter, categorize, edit, import, and export transaction history.
- Understand income, spending, recurring expenses, category breakdowns, and money movement in Cash Flow.
- Track investments, allocation, performance, options, crypto, dividends, and interest income.
- Add cash, property, vehicles, private investments, debt, and other accounts manually when they cannot be connected.
- Keep financial data and saved authentication material on your own computer in an encrypted SQLCipher database.
- Install a self-contained desktop package with the frontend, backend, and managed runtime included.
