# BreakTwenty 1.0.4

## Changes

- RBC flow adapted to new official RBC page redirect.
- Interactive Brokers Flex sync now downloads each report from the endpoint IBKR assigns, preventing false report-generation delays.
- Diagnostic runs and provider evidence now use bounded storage names while preserving complete sync metadata, so every generated attempt remains listable and exportable regardless of result-name length.
- Saved Interactive Brokers scraper credentials now reliably prefill the secure login form during manual recovery.
- Managed provider sign-in windows on Linux now open properly while the bank page loads.
- Updated bundled application and networking runtimes with upstream security fixes.
