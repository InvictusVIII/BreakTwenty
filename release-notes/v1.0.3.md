# BreakTwenty 1.0.3

## Changes

- Slow IBKR Flex reports now keep existing data and show an amber Sync delayed status instead of a connection failure.
- Autosync and Sync All recover from more brief DNS, VPN, and network-interface interruptions while preserving completed data and reporting failures when recovery is exhausted.
- Linux startup now recognizes the secure credential provider actually used by Electron, preventing false plaintext-storage failures when Secret Service or KWallet is available.
- Desktop startup now recovers from brief operating-system credential-store interruptions without weakening encrypted database protection.
- Moomoo request-validation failures now report as sync errors instead of incorrectly asking you to reconnect, while expired or insufficient authorization still uses the reconnect path.
