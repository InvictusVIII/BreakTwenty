# BreakTwenty 1.0.2

## Changes

- Scotiabank secure login now retains short-lived credentials more reliably across platforms, with an additional Windows request-bound capture guard for the previously failing add flow.
- Packaged apps now preserve the six-hour autosync cooldown, chart colors, zoom level, market/news fallbacks, and other interface preferences across restarts without retaining local API responses in Chromium's disk cache.
- Closing the app during sync now resumes only unfinished provider work on the next launch, and the sidebar sync badge no longer counts providers that already finished.
- Application diagnostic ZIP names now use the saved app timezone and daylight/standard abbreviation, matching provider diagnostic archives.
- Restart-recovery diagnostics now label successful resumptions as recovery information instead of errors.
- Closing the last window on macOS now fully shuts down the app, so reopening starts cleanly without hanging on the loading screen.
